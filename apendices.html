    13. Apéndices

    13.1. Instalación de Python

    [Python] puede descargarse desde python.org/downloads. Los ejemplos y el caso de estudio requieren la versión 3.12 o posterior; se probaron con la versión 3.13.

    En [Windows], el instalador muestra en su primera pantalla la casilla “Add python.exe to PATH”: debe marcarla. El comando [python] queda entonces disponible en todos los terminales. El instalador también instala el lanzador [py], que permite seleccionar una versión cuando hay varias instaladas ([py -3.13]). También puede usar el administrador de paquetes [winget]:

    1
    winget install Python.Python.3.13

    En [macOS], use el instalador [.pkg] de la misma página, o el administrador de paquetes [Homebrew] ([brew install python@3.13]). En [Linux], [Python] normalmente ya está instalado; verifique su versión y, si es necesario, instale el módulo [venv], que crea los entornos virtuales (en [Ubuntu]: [sudo apt install python3-venv]). En [macOS] y [Linux], el comando suele llamarse [python3] (y [pip3]): es el comando que se usa para crear el entorno virtual. Una vez activado el entorno, [python] y [pip] se refieren a los del entorno.

    Verifique la instalación en una consola nueva ([PowerShell], símbolo del sistema o terminal):

    1
    python --version

    lo cual debe mostrar un número de versión igual o superior a 3.12 (por ejemplo, [Python 3.13.7]). Con una versión anterior, el caso de estudio se detiene al iniciar por un error de sintaxis (véase “Problemas comunes”).

    13.2. Entornos virtuales y pip

    Un entorno virtual es una carpeta (en este caso, [.venv]) que contiene una copia del intérprete de [Python] y las bibliotecas de un proyecto. Así, cada proyecto tiene las suyas, en las versiones que le convienen. La carpeta [examples] tiene su propio entorno, compartido por los 28 ejemplos; el caso de estudio tiene el suyo.

    Comandos útiles, en [Windows] (en [Linux] y [macOS], [source .venv/bin/activate] para la activación):

    1
2
3
4
5
    python -m venv .venv               # crear el entorno (una sola vez)
.venv\Scripts\activate             # activarlo (en cada terminal nuevo)
pip install -r requirements.txt    # instalar las bibliotecas del proyecto
pip list                           # las bibliotecas instaladas
deactivate                         # desactivar el entorno

    [pip] descarga las bibliotecas del repositorio [PyPI] (pypi.org): se requiere conexión a Internet durante la instalación. Si se encuentra detrás de un proxy corporativo, especifique el proxy con la opción [--proxy] de [pip]. El entorno virtual no puede copiarse de una máquina a otra (contiene rutas absolutas): debe recrearse con el archivo [requirements.txt]. Por eso la carpeta [.venv] no se incluye en los materiales del curso.

    13.3. Instalación de Visual Studio Code

    Descargue [Visual Studio Code] desde code.visualstudio.com. Agregue la extensión Python de Microsoft (menú Ver / Extensiones, y luego busque “Python”): esto también instala [Pylance] (autocompletado, verificación de tipos, informe de errores) y el Python Debugger. Una extensión como Better Jinja agrega resaltado de sintaxis a las vistas [Jinja2] (archivos HTML que contienen etiquetas {{ }} y {% %}).

    Abra la carpeta [examples] o la carpeta del caso de estudio (menú Archivo / Abrir carpeta). La extensión detecta el entorno virtual [.venv] y le propone usarlo: acepte la propuesta (también puede seleccionarlo con el comando Python: Select Interpreter, teclas [Ctrl-Shift-P]). La terminal integrada (menú Terminal / Nueva terminal) activa entonces automáticamente el entorno, lo que permite ejecutar las aplicaciones sin salir del editor. La tecla [F5], en el archivo [app.py], ejecuta la aplicación bajo el control del depurador (véase “Modo de desarrollo”).

    13.4. Instalación de MySQL con Laragon

    [Laragon] (laragon.org) instala, listo para usar, un servidor [MySQL] (o [MariaDB]), junto con la herramienta de administración [HeidiSQL]. Después de la instalación:

    • el botón "Start All" inicia el servidor [MySQL] en el puerto 3306;
    • el usuario [root] no tiene contraseña: son los valores predeterminados del ejemplo 28 ([DATABASE_URL]) y del caso de estudio ([DB_USER], [DB_PASSWORD]);
    • el botón Database abre [HeidiSQL], donde el menú File / Run File SQL ejecuta los scripts [dbpersons.sql] (ejemplo 28) y [dbrdvmedecins2.sql] (caso de estudio).

    En [Linux] o [macOS], instale [MySQL] o [MariaDB] con el administrador de paquetes del sistema y ejecute los scripts con el cliente de línea de comandos [mysql]. El controlador [PyMySQL] funciona con ambos sin ninguna configuración. En [Linux], la cuenta [root] de [MariaDB] suele estar configurada para iniciar sesión solo mediante la cuenta del sistema [root] ([sudo mysql]): en ese caso se crea un usuario para las aplicaciones y se especifica en su configuración:

    1
    sudo mysql -e "CREATE USER 'course'@'localhost' IDENTIFIED BY 'course'; GRANT ALL ON *.* TO 'course'@'localhost';"

    13.5. Instalación de curl

    [curl] viene incluido en [Windows] 10 y 11, [macOS], y en la mayoría de las distribuciones de [Linux]. En [PowerShell], debe escribir [curl.exe], no [curl]: en versiones antiguas de [PowerShell], [curl] es un alias de otro comando ([Invoke-WebRequest]), que tiene opciones diferentes. En el símbolo del sistema de [Windows] ([cmd]), las comillas de una cadena JSON se escriben [\"] (ejemplo 11), y una URL que contenga [&] debe ir entre comillas dobles.
